# Cyprien Vial

**Machine learning engineer.** I work on the part of a problem where the map runs out — messy data, shifting distributions, systems that have to hold up outside the conditions they were trained on.

Most of what I build starts the same way: a domain I don't understand yet, a dataset that doesn't behave, and a stubborn interest in finding out what's actually there. Medical imaging, satellite data, road accidents, football, language. Different terrain, same instinct.

I care less about models that score well on a benchmark than about models that survive contact with the real world.
